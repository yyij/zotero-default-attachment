# 默认附件

[English](README.en.md)

为 Zotero 条目指定一个双击时打开的附件。适合一篇文献同时有原文、译文和补充材料的情况。

## 安装和更新

安装范围为 **Zotero 10.0.7 及更新的 10.0.x**。如果使用其他 Zotero 版本，请自行测试兼容性。从仓库的 Releases 下载 [`default-attachment-choice-1.2.2.xpi`](https://github.com/yyij/zotero-default-attachment/releases/tag/v1.2.2)，在 Zotero 中打开「工具 → 插件」，点击齿轮并选择「从文件安装插件」。更新时直接选择新版 XPI 覆盖安装，已有的默认附件设置会保留。

## 使用方法

1. 展开父条目，右键单个文件附件，选择「设为此条目的默认附件」。
2. 双击父条目打开该附件。右键父条目可定位或取消默认附件。
3. 多选父条目后右键打开「批量设置默认附件…」。选择匹配对象、条件和关键词，预览后点「应用」。

例如，按文件名匹配「结尾是 译文」，会命中 `论文译文.pdf`，因为文件名匹配会忽略扩展名。同一条目有多个匹配时，需要在预览中选择一个，否则会跳过。默认保留已有设置，可勾选覆盖。右键菜单可撤销上一次批量更改，之后手动修改过的条目会保留。

## 语言和本机设置

菜单、批量窗口和提示随 Zotero 界面语言显示中文或英文，其他语言回退为英文。默认附件设置存放在本机 Zotero 配置中。附件重命名后设置仍可用。附件不可用时，插件会提示并交回 Zotero 按原方式打开。
